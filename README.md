# MG Company: landing page de sessão estratégica gratuita

Landing page para uma sessão estratégica gratuita voltada a empresários e empreendedores digitais que querem estruturar e escalar seus negócios com previsibilidade.

## Objetivo

Teste prático de front-end para demonstrar HTML5 semântico, CSS3 organizado e responsividade.

## Tecnologias

- HTML5
- CSS3
- Google Fonts: Newsreader (títulos) e Instrument Sans (texto)
- Font Awesome 6 (via CDN, apenas para ícones decorativos, todos com `aria-hidden`)
